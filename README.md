# QuizLive

### تابع و اربح — *"Follow & Win"*

**QuizLive** is a real-time, AI-driven quiz platform built on top of live TV and radio broadcasts. It was designed and built during a **hackathon organized by 3SG Group in collaboration with ENIT Junior Entreprise**.

---

## English

### 1. The idea

Media and advertising companies want to know, in real time, how many people are actually watching or listening — and how engaged they are — without ever collecting personal data about the audience.

**QuizLive** solves this by turning any live TV/radio stream into a real-time, gamified quiz:

- The platform "watches" and "listens" to the live broadcast continuously.
- AI decodes what is happening on screen and in the audio right now.
- Within seconds, it generates a multiple-choice question about the current moment of the show and pushes it live to every connected viewer.
- Viewers answer from their phone through a lightweight account (email/password) used only to track their own points and rewards — no camera, no microphone, no viewing-habits tracking of any kind.
- The media/advertising company gets aggregated, real-time engagement analytics (audience size, answer distribution, attention over time) — real signal for advertisers, without ever exposing which individual viewer answered what.

AI is present at every single step of the pipeline:

| Step | AI involved |
|---|---|
| Reading the live video feed | YOLOv8 (object / on-screen element detection) |
| Reading on-screen text (lower-thirds, captions, guest names) | PaddleOCR (Arabic) |
| Understanding what's being said | OpenAI Whisper (Arabic speech-to-text) |
| Turning the current moment into a quiz | Groq (Llama 3.3 70B) generating a structured question in real time |

The result: a live audience-engagement product where the entertainment (the quiz) and the business value (privacy-safe real-time stats for the broadcaster/advertiser) are generated by the exact same AI pipeline, at the exact same time.

### 2. Architecture

```
QuizLive/
├── api/                  FastAPI service — the real-time AI pipeline
│   └── main.py           yt-dlp/ffmpeg live capture -> Whisper transcription -> Groq quiz generation
├── agent/                Standalone prototype of the transcription -> quiz pipeline
├── cv-worker/            Computer-vision exploration scripts
│   ├── test_yolo.py      YOLOv8 object detection on video frames
│   ├── test_ocr.py       PaddleOCR text extraction from the on-screen caption band
│   └── test_whisper.py   Whisper transcription tests
├── DABLyou/              The product: mobile app + backend
│   ├── backend/          NestJS + Prisma + PostgreSQL + Socket.IO
│   └── mobile/           Flutter app (Arabic, RTL)
├── videos/               Local sample media for offline development (gitignored)
└── start-dev.ps1         One-command local dev launcher
```

**Data flow:**

```
YouTube live URL --> yt-dlp (resolve HLS) --> ffmpeg (extract 30s audio) --> Whisper (ar transcript)
                                                                                    |
                                                                                    v
                                                                    Groq . Llama 3.3 70B (JSON quiz question)
                                                                                    |
                                                                                    v
                                            NestJS backend --Socket.IO--> Flutter app (viewers answer live)
                                                    |
                                                    v
                                    Points . Rewards . Coupons . Aggregated analytics dashboard
```

### 3. Tech stack

- **AI / Computer vision:** OpenAI Whisper, Groq (Llama 3.3 70B), Ultralytics YOLOv8, PaddleOCR, OpenCV
- **Media ingestion:** yt-dlp, ffmpeg (HLS live capture + audio extraction)
- **AI service:** Python, FastAPI, Uvicorn
- **Backend:** NestJS, Prisma, PostgreSQL, Socket.IO, JWT auth
- **Mobile:** Flutter (Dart), Arabic/RTL UI
- **Infra (dev):** Docker Compose (Postgres/Redis), PowerShell dev launcher

### 4. Getting started

**Prerequisites:** Python 3.10+, Node.js 20+, PostgreSQL (local service or Docker), Flutter SDK, ffmpeg.

```bash
# 1. Configure secrets
cp .env.example .env                          # add your GROQ_API_KEY
cp DABLyou/backend/.env.example DABLyou/backend/.env

# 2. AI service (FastAPI)
cd api
pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000

# 3. Backend (NestJS) — in a separate terminal
cd DABLyou/backend
npm install
npx prisma migrate dev --name init
npm run prisma:seed
npm run start:dev

# 4. Mobile app (Flutter) — in a separate terminal
cd DABLyou/mobile
flutter run -d chrome
```

Or, on Windows, run everything at once with:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-dev.ps1
```

Drop a sample video at `videos/fsf_ep36.mp4` to test the pipeline offline, or set `LIVE_STREAM_URL` in `.env` to point at a real YouTube live stream.

### 5. Key API surface

**AI service (FastAPI, `:8000`)**
- `GET /` — health check
- `GET /stream-status?stream_url=` — resolve/inspect a live stream's HLS URL
- `GET /generate-question?stream_url=&start_time=` — run the full pipeline and return a generated quiz question

**Backend (NestJS, `:3000`)**
- `POST /auth/register`, `POST /auth/login`
- `GET /me`, `PATCH /me`, `DELETE /me`
- `GET /media?type=TV|RADIO`, `POST /media/select`
- `POST /gameplay/answer`
- `GET /rewards`, `POST /rewards/redeem`
- `GET /coupons/mine`, `POST /coupons/:id/use`
- `GET /points/history`
- **WebSocket** namespace `/live`, room `media:{mediaId}`, event `question` pushed to all viewers

### 6. Roadmap

- **Phase 1 (hackathon MVP):** simulated/manual question generation, real-time delivery pipeline — done
- **Phase 2:** full AI pipeline — live stream ingestion, ASR, computer vision, Groq-generated questions — done
- **Phase 3:** sponsored "secret word" ad campaigns — ad detection, short-validity-window bonus questions, aggregated brand analytics

### 7. Privacy by design

Playing only requires a lightweight account (email/password) to track points and rewards — QuizLive never turns on a viewer's camera or microphone, and never profiles their viewing habits. The AI pipeline only reads the broadcast itself (the show), not the audience. Everything the broadcaster/advertiser sees is aggregated (counts, distributions, trends); no individual viewer's identity or answers are ever exposed to them.

## Français

### 1. L'idée

Les entreprises média et les annonceurs veulent savoir, en temps réel, combien de personnes regardent ou écoutent réellement un programme — et à quel point elles sont engagées — sans jamais collecter de données personnelles sur cette audience.

**QuizLive** répond à ce besoin en transformant n'importe quel live TV/radio en quiz en temps réel et gamifié :

- La plateforme « regarde » et « écoute » en continu le direct.
- L'IA décode ce qui se passe à l'écran et à l'oral, à l'instant même.
- En quelques secondes, elle génère une question à choix multiples sur le moment présent de l'émission et la diffuse en direct à tous les spectateurs connectés.
- Les spectateurs répondent depuis leur téléphone via un compte léger (email/mot de passe) utilisé uniquement pour suivre leurs propres points et récompenses — pas de caméra, pas de micro, aucun suivi des habitudes de visionnage.
- L'entreprise média/annonceur obtient des statistiques d'engagement agrégées en temps réel (taille d'audience, répartition des réponses, courbe d'attention) — un vrai signal business pour les annonceurs, sans jamais savoir quel spectateur a répondu quoi.

L'IA est omniprésente à chaque étape du pipeline :

| Étape | IA utilisée |
|---|---|
| Lecture du flux vidéo en direct | YOLOv8 (détection d'objets / d'éléments à l'écran) |
| Lecture du texte affiché (bandeaux, sous-titres, noms d'invités) | PaddleOCR (arabe) |
| Compréhension de ce qui est dit | OpenAI Whisper (transcription arabe) |
| Transformation du moment en question de quiz | Groq (Llama 3.3 70B), génération structurée en temps réel |

Résultat : un produit d'engagement d'audience live où le divertissement (le quiz) et la valeur business (des statistiques temps réel respectueuses de la vie privée pour la chaîne/l'annonceur) sont générés par le même pipeline d'IA, au même instant.
